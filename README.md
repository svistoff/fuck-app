# Знакомства — локальный сайт знакомств для одного города

Серверный рендеринг (Node + Express + SQLite), без SPA — ради SEO и простоты эксплуатации.
Один процесс Node, база в файле, фото на диске VPS.

## Что умеет

- **Главная и каталог открыты всем** (без входа) — с фото и кликабельными контактами. Это нужно для индексации в поиске.
- **Регистрация/вход по email (magic link)** — без пароля. Ссылка действует 30 минут.
- **Анкеты создают только женщины**: имя, возраст, район/улица (необязательно), краткое и полное описание, до 4 фото, контакты.
- **Контакты 6 типов**: телефон (звонок), WhatsApp (по номеру), Telegram / MAX / Instagram (по username), BiP (по номеру).
- **Карусель**: каждые 15 минут верхняя анкета уходит вниз, по кругу. Порядок считается от времени — без фоновых задач.
- **Админка** (отдельный вход логин+пароль): статистика, просмотр/редактирование/скрытие/удаление анкет, удаление любых фото, закрепление анкет наверху, управление SEO-страницами и мета-данными главной.
- **SEO**: серверный HTML с title/H1/description/keywords на каждой странице, `robots.txt`, `sitemap.xml`, и раздел низкочастотных посадочных страниц под ключевые запросы.
- **18+**: оверлей-подтверждение возраста (контент остаётся в HTML и индексируется).

## Требования

- Node.js 18+ (рекомендуется LTS — 20 или 22 LTS; для них есть готовые бинарники `better-sqlite3`).
- VPS с nginx (раздаёт HTTPS и статику) и доменом.
- Аккаунт [Resend](https://resend.com) с верифицированным доменом (для писем).

## Установка на VPS

```bash
git clone <repo> /var/www/example.ru
cd /var/www/example.ru
npm install --omit=dev
cp .env.example .env
```

Заполни `.env`. Сгенерируй секреты:

```bash
# SESSION_SECRET
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# ADMIN_PASS_HASH (подставь свой пароль)
node -e "console.log(require('./src/auth').hashPassword('ТВОЙ_ПАРОЛЬ'))"
```

Скопируй полученные значения в `.env` (`SESSION_SECRET` и `ADMIN_PASS_HASH`).
Укажи `BASE_URL` (свой домен, без слэша в конце), `CITY_NAME`, `MAIL_FROM`, `RESEND_API_KEY`,
и `UPLOAD_DIR` (абсолютный путь, напр. `/var/www/example.ru/uploads`).

## Почта (Resend)

1. Заведи домен в Resend → добавь предложенные DNS-записи (SPF, DKIM, при желании DMARC).
2. Дождись статуса «Verified».
3. `MAIL_FROM` должен быть на этом домене, напр. `Знакомства <noreply@example.ru>`.
4. Без верификации письма уходят в спам. Бесплатного тарифа (3000 писем/мес) хватает для входов.

На время локальной отладки поставь `MAIL_DEV_LOG=1` — ссылка будет печататься в консоль, письмо не отправляется.

## Запуск

```bash
# напрямую
npm start

# через pm2 (рекомендуется)
npm i -g pm2
pm2 start ecosystem.config.js
pm2 save && pm2 startup
```

## Nginx

Смотри `nginx.example.conf`. Главное:
- HTTPS-сертификат (Let's Encrypt / certbot);
- `location /uploads/` отдаёт фото напрямую с диска (`alias` на твой `UPLOAD_DIR`);
- всё остальное проксируется на `127.0.0.1:8080`;
- `client_max_body_size 12m;` под загрузку фото.

## Админка

`https://example.ru/admin/login` — логин из `ADMIN_USER`, пароль тот, для которого сгенерирован `ADMIN_PASS_HASH`.

### SEO-страницы под ключевые слова

Админка → «SEO-страницы» → «Новая страница». Указываешь:
- **URL (slug)** — адрес вида `example.ru/znakomstva-v-tsentre` (латиница, цифры, дефисы);
- **Title / H1 / Meta description / Ключевые слова** — то, что видит поиск;
- **Текст (HTML)** — содержимое страницы.

Страница сразу попадает в `sitemap.xml` и доступна по своему адресу. Так можно постепенно
добавлять низкочастотные посадочные страницы и наращивать видимость в выдаче.

Мета-данные и вступительный текст главной правятся в Админка → «Настройки».

## Что пока упрощено (можно добавить позже)

- **BiP**: точная схема ссылки на диалог не подтверждена — пока используется звонок по номеру (`tel:`). Уточнить на реальном устройстве (`src/contacts.js`).
- **18+**: это подтверждение (галочка-оверлей), а не проверка по документам.
- **Жалобы и блокировки**: убраны по решению — добавляются отдельно при необходимости.
- **Локация**: текстовое поле «район/улица», без карты.
- **Иконки мессенджеров**: простые глифы-заглушки в `src/views.js` (функция `icon`). Для прода замени на официальные SVG.

## Структура

```
src/
  config.js     — конфигурация из .env
  db.js         — SQLite (better-sqlite3) + применение schema.sql
  contacts.js   — типы контактов и сборка ссылок
  mailer.js     — отправка magic-link через Resend
  auth.js       — сессии (подписанные cookie), хеш пароля, токены входа
  rotation.js   — карусель (порядок от времени)
  views.js      — рендер публичных страниц и кабинета
  views_admin.js— рендер админки
  server.js     — маршруты
public/         — css, js, картинки
schema.sql      — схема БД
uploads/        — фото (на проде — отдельный путь)
data/           — файл базы (создаётся автоматически)
```
